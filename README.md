# SMIT AI & DS Project - My Portfolio

### Project Overview

This repository contains a personal portfolio website developed as part of the **Artificial Intelligence & Data Science (AI & DS)** program at **Saylani Mass IT Training (SMIT)**.

The project is built using **Python**, **Django**, **HTML**, and **CSS** to showcase my technical skills, academic projects, certifications, and web development experience through a clean and responsive portfolio website. It serves as a centralized platform to present my learning journey, projects, and achievements in a professional manner.

### Prerequisites

Before running this project, ensure you have the following software installed on your computer:

- Python 3.x or later
- Django
- Git (Optional)
- Visual Studio Code (Recommended)

#

### Installation

1. Clone the repository:

```bash
git clone https://github.com/sheikhjunaidahmedofficial/SMIT-AI-DS-Project-My-Portfolio.git
```

2. Open the project folder in **Visual Studio Code**.

3. Create a virtual environment:

```bash
python -m venv portfolio_venv
```

4. Activate the virtual environment.

**Windows**

```bash
portfolio_venv\Scripts\activate
```

**macOS / Linux**

```bash
source portfolio_venv/bin/activate
```

5. Install Django:

```bash
pip install django
```

6. Navigate to the project directory:

```bash
cd "Django Portfolio"
```

#

### How to Run

1. Apply database migrations:

```bash
python manage.py migrate
```

2. Start the Django development server:

```bash
python manage.py runserver
```

3. Open your browser and visit:

```text
http://127.0.0.1:8000/
```
